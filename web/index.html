MODEL GUIDE

Inside the translator

A 32-unit recurrent encoder reads English words in order. At each decoding step, a learned query scores the encoder states. Softmax converts these scores into the weights shown in one heatmap row.

Reading the heatmap

Columns are English source tokens. Rows are generated Spanish tokens. A darker cell means more attention to that encoder state. Each row sums to one before rounding. An encoder state also contains information from earlier words.

Training domain

The model trained on 13,500 distinct generated sentence pairs. It translated all 1,500 held-out pairs exactly. These pairs use the same grammar and vocabulary as training.
